# MT Verdant Nocturne — GDM Login Screen Styling

© Mayanktaker Computers & Web Development | https://mayanktaker.com

Custom styling and wallpaper configuration for the GNOME Display Manager (GDM).

## Application
In GNOME, GDM styling is compiled into `/usr/share/gnome-shell/gnome-shell-theme.gresource`.
You can apply `gdm.css` using standard GDM theme utilities like `gdm-settings` or `loginized`:

1. Using `gdm-settings`:
   - Open `gdm-settings` GUI.
   - Go to **Appearance** -> **Shell Theme** -> Select `MT-Verdant-Nocturne`.
   - Set Background to `~/.themes/MT-Verdant-Nocturne/wallpapers/mt-verdant-canopy-3840x2160.png`.
   - Click **Apply**.
