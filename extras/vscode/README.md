# MT Verdant Nocturne — VS Code Theme

© Mayanktaker Computers & Web Development | https://mayanktaker.com

Companion VS Code dark theme with syntax colors tailored to the MT Verdant Nocturne palette.

## Installation
Copy this folder into your VS Code extensions directory:
```sh
mkdir -p ~/.vscode/extensions/mt-verdant-nocturne-theme
cp -r package.json themes/ ~/.vscode/extensions/mt-verdant-nocturne-theme/
```
Then restart VS Code and select **MT Verdant Nocturne** from `Preferences: Color Theme` (`Ctrl+K Ctrl+T`).
