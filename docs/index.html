Quick Installation & Customization

Zero root permissions required. Installs safely into ~/.themes and ~/.icons.

1. Interactive CLI Wizard

Launch our friendly step-by-step terminal wizard to preview options:

git clone https://github.com/Mayanktaker/mt-verdant-nocturne.git
cd mt-verdant-nocturne
./install.sh

2. Botanical Accent Flavors

Choose your primary highlight color flavor:

Sage (#8FB8A6) — Default
Emerald (#3DD68C)
Moss (#9ECB74)
Pine (#3D8B7A)

3. Direct CLI Command Flags

# Recommended: Rounded floating island tray + standard buttons:
./install.sh --panel round-island --controls standard

# Floating pill capsule + macOS traffic dots:
./install.sh --panel pill --controls macos

# Screen-attached bottom-rounded bar:
./install.sh --panel bottom-round

# Classic edge-to-edge square bar:
./install.sh --panel flat

# Compact high-density mode without blur (laptops & low-GPU):
./install.sh --size compact --no-blur

4. Standalone Icon & Cursor Pack (Any Linux Desktop)

For users wanting only MT-Verdant-Icons on GNOME, KDE Plasma, XFCE, Cinnamon, Sway, or Hyprland:

# Download & install the standalone icon suite
curl -sSLO https://github.com/Mayanktaker/mt-verdant-nocturne/releases/download/v0.2.0/mt-verdant-icons-v0.2.0.tar.xz
tar -xf mt-verdant-icons-v0.2.0.tar.xz && cd mt-verdant-icons-v0.2.0 && ./install.sh
